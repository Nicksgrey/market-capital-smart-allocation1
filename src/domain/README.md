# Domain (Camada de Domínio)

Entidades, value objects, enums e contratos de repositório do Motor Inteligente
de Alocação Patrimonial. **Sem** dependências de framework, Supabase ou React.

- `entities/` — modelos de negócio puros
- `value-objects/` — tipos com invariantes (percentuais, moeda, risco)
- `repositories/` — interfaces que a camada de infraestrutura implementa
